# Draw Your World：温暖艺术型 UX 竞品研究

研究日期：2026-11-16。面向电脑优先的绘画表达原型，目标是降低开始表达的压力、保留自主权，让作品成为交流中心。本文件是设计建议，不构成疗效判断，也不将竞品产品文案当作医学证据。

## 证据范围

本轮查看六类相邻产品的官方页面、开发者官方商店说明及 Apple 设计访谈；额外下载并实际查看 TIDE、Headspace、Reflectly 的官方公开界面图片。没有登录或安装这些应用，因此不声称完成竞品完整可用性测试。官网传播画面与当下真实应用可能不同；Headspace 图像来自明确标注 2023 年的历史访谈。

研究图片仅保存在被 Git 忽略的 `output/ux-research/`，用作对照，不能直接进入产品资产。

## 推荐方向：暖光下的个人画室

这是根据以上证据与用户偏好形成的设计推论，不是任何竞品的既定结论。核心借鉴组合为 TIDE 的克制、Headspace 的可接近、Lake 的作品中心；Finch 仅借鉴语气，How We Feel 仅借鉴可选表达支架。

温暖不必来自满屏奶油色。建议用较中性的暖白大面、轻微材料差异、有限的草木色及一处暖色，让画作内容产生主要色彩。艺术性集中在入口的一幅原创画室场景、字体的节奏以及画纸的比例。工作台进入后撤去大部分装饰。

- **空间顺序**：环境背景最安静，纸张承载作品，对话像纸旁的笔记；这三层通过空间、色差与一个轻阴影区分，不需要每层都有边框。
- **层次**：入口先见画室气氛和一个主动作；画画阶段先见画布；聊天阶段先见原作和当前对话；变化阶段才展示改动清单。
- **英文排版**：主界面使用英文；入口以大字号衬线标题和较小无衬线正文形成明显反差，工作台让标题退让给画作。标题不拆分单词染色。大段解释收起到 About this space 等说明入口。
- **形状**：画纸保留近似矩形；按钮可以柔和；不要全站统一大圆角。
- **动效（按用户新偏好更新）**：允许丰富且有层次的界面动态，以进入画室、选择创作方式、添加形状、展开对话、确认改动、切换作品与收纳结果组成连续动效语言。动态呈现变化而非虚构生成进度；创作中的画布不持续漂移。支持减少动态效果，并保留同等清楚的静态状态。
- **素材边界**：竞品图片只用于研究；入口素材应原创。用户提交给模型的画布保持干净。

设计 token 的具体色值、间距及构图由 UI 负责人确定，开发遵循其规范，不能把本研究的方向性建议当作替代设计稿的自由裁量。

## 旅程与用语

1. **邀请**：说明“画几笔，也可以从一张已有的画开始”。一个主入口；示例是次入口，不默认灌入画布。
2. **创作**：工具就近，当前工具明确，撤销容易找到。允许直接聊画，也允许安静画完。
3. **被理解**：先回应用户已经说的内容。情绪词是可选支架，不能每轮问卷式追问。原作始终可见。
4. **轻邀约**：“试一点变化”“继续聊”“保留原样”都能正常推进；后两者不作为失败状态。
5. **确认**：把“改变什么／保留什么”并列，让用户能够修改；只有此处确认才真正执行。
6. **等待与回看**：等待生成不锁死聊天；结果可比较、接受或舍弃；失败不失去画作。
7. **收尾**：允许“今天先到这里”；可选记录感受，不强求给出积极评价。

示例语气：“夜色就留着，只给窗里添一点光。”避免“检测到你的孤独”“你的情绪改善了”“完成今日疗愈任务”等判断或压力。

## 给 UI 与开发的验收建议

以下是本项目提出的验收规则，不冒充竞品通用标准。

| 维度 | 可检查的标准 |
|---|---|
| 主次 | 任一主要状态最多一个强主按钮；入口、画布、聊天、确认阶段分别能在三秒内辨认当前动作。 |
| 留白 | 桌面画作是面积最大的内容块；对话不被多层同色卡片挤占；主要文本边缘留出稳定间距。 |
| 温暖 | 抽掉插画后，语气、材料色差和空间仍显得友好；不能只依赖表情或一句口号。 |
| 艺术感 | 一个可识别的原创画室视觉；没有图库式装饰堆叠；已画作品不会和背景插画竞争。 |
| 可读性 | 正文建议至少 16px，正文对比度至少 4.5:1；关键操作不用只有图标的神秘按钮。 |
| 自主权 | 可跳过感受、不改画、取消等待、舍弃结果；这些操作都可见且保持正常语气。 |
| 真实状态 | Live/Demo、未配置、失败、处理中能够识别；不能以动效或静态图伪装生成成功。 |
| 适配 | 1440×900、1280×720、390×844 检查无横向溢出；移动端工具、发送和返回作品仍可达。 |
| 无障碍 | 键盘焦点可见、弹窗能退出、减少动态效果生效；不依赖颜色单独表达选择或错误。 |

## 原型与实装比较方式

每轮按同一视口、同一状态、同一示例内容截图：入口、空白画布、对话中、改动确认、生成结果、失败恢复、窄屏。UI 负责人按构图比例、字体层级、密度、控件显著性和文案记录偏差，再给开发明确修正。技术不可行项先给 UI 提案，不能由开发静默删减或换一种布局。

本轮本地视觉证据：`output/ux-research/tide.png`、`headspace.jpg`、`reflectly.png`。文件来自上述官方公开 URL，仅为研究参考。

## 用户新增偏好：英文、大字号反差、丰富动态

本节优先于前文任何偏向静态或中文排版的建议。实际产品界面以英文为主。研究文档可以继续中文，方便团队沟通。

建议入口用明显大于正文的 display 标题（例如 72–88px 对 16–18px 正文，最终以 UI 规格与实测为准），通过字形、行距、换行与大片空间形成艺术性，而不是添加更多卡片。工作台标题按画布空间收敛，防止大标题侵占创作操作。390px 宽度单独调整，不能简单等比例压缩。

竞品启发是 TIDE 的大问候与安静场景、Headspace 的插画表达；这些属于公开画面的视觉观察。这里提出的展纸、场景分层、形状进入、对话展开与结果收纳动效是本项目设计提案，不宣称是上述竞品已验证的动画机制。

丰富动态可分布于不同用户动作，避免同一时刻所有部件一起运动。关键点击不应被长动画阻塞；焦点、输入光标与用户正在拖动的对象应稳定。实际生成等待不配假百分比。用户主动选择减少动态效果时立即呈现相同信息与操作。
